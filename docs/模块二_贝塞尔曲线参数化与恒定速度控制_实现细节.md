# 模块二：贝塞尔曲线参数化与恒定速度控制 — 实现细节

> 本文档基于 `include/bezier_tracking/bezier_curves.hpp` 和 `src/bezier_curves.cpp` 的源代码，对算法核心模块二的实现进行逐层拆解。模块二负责：**用线性/二次/三次贝塞尔曲线参数化路径，并计算使虚拟机器人沿曲线以恒定速度运动的参数变化率 $\dot{\lambda}$**。

---

## 一、模块概述

模块二为"理想机器人"（pursuee）提供运动学基础设施：
1. **路径参数化**：用贝塞尔曲线定义理想机器人在平面上的参考轨迹；
2. **恒定速度控制**：给定期望速度 $V$，计算贝塞尔曲线参数 $\lambda$ 的变化率 $\dot{\lambda}$，使得 $|\frac{dP}{dt}| = V$；
3. **分段组合**：将多段贝塞尔曲线拼接成复杂路径（`Map` 类）。

### 输入输出

| 输入项 | 说明 |
|---|---|
| 控制点 $P_0, P_1, ..., P_n$ | 定义贝塞尔曲线的几何控制点 |
| 期望速度 $V$ | 虚拟机器人沿曲线的运动速度 |
| 全局参数 $\lambda$ | 当前在分段贝塞尔路径上的位置（全局坐标） |

| 输出项 | 说明 |
|---|---|
| $P(\lambda) = [P_x, P_y]^T$ | 曲线上对应参数 $\lambda$ 的位置 |
| $\vec{v}(\lambda) = [\dot{P_x}, \dot{P_y}]^T$ | 曲线上对应参数 $\lambda$ 的速度向量 |
| $\dot{\lambda}$ | 参数变化率，用于积分更新 $\lambda$ |

---

## 二、类继承体系设计

项目采用经典的**多态继承**结构，基类 `BezierCurve` 定义接口，三个派生类分别实现线性、二次、三次贝塞尔曲线。

```
BezierCurve (抽象基类)
├── LinearBezier
├── QuadraticBezier
└── CubicBezier

Map (组合器，管理 BezierCurve* 数组)
```

### 2.1 基类 BezierCurve（bezier_curves.hpp:7-16）

```cpp
class BezierCurve{
    public:
        virtual void  get_point(float lambda, float &x, float &y) = 0;
        virtual void  get_velocity(float lambda, float lambda_vel, float &vx, float &vy) = 0;
        virtual float lambda_velocity(float lambda, float velocity) = 0;
        virtual std::string bezier_type();
        virtual std::vector<std::array<float,2>> get_control_points();

        float lambda_diff = 0;  // 搜索步长（模块三使用）
};
```

| 纯虚函数 | 职责 |
|---|---|
| `get_point` | 计算参数 $\lambda$ 处的位置 $P(\lambda)$ |
| `get_velocity` | 计算参数 $\lambda$ 和 $\dot{\lambda}$ 处的速度 $\frac{dP}{dt}$ |
| `lambda_velocity` | 计算维持恒定速度 $V$ 所需的 $\dot{\lambda}$ |

### 2.2 为什么使用继承 + 多态？

`Map` 类存储 `std::vector<BezierCurve*>`，通过基类指针统一调用不同阶次贝塞尔曲线的实现。这使得路径规划器（模块一）无需关心当前路径段是线性、二次还是三次——**多态隐藏了实现差异**。

## 三、线性贝塞尔曲线（LinearBezier）

### 3.1 数学基础

$$P(\lambda) = (1-\lambda)P_0 + \lambda P_1, \quad \lambda \in [0, 1]$$

### 3.2 构造函数与 lambda_diff

```cpp
LinearBezier::LinearBezier(Params params):params_(params){
    lambda_diff = std::sqrt(
        std::pow(params_.dstep, 2) / 
        (std::pow(params_.x_end - params_.x_start, 2) + 
         std::pow(params_.y_end - params_.y_start, 2))
    );
}
```

**lambda_diff 的推导**：

`lambda_diff` 是模块三（一维搜索）中沿 $\lambda$ 方向的搜索步长。其设计目标是：在参数空间中走一步，对应的几何位移约为 `dstep`。

线性贝塞尔曲线的参数-几何关系是线性的：
$$\frac{dP}{d\lambda} = P_1 - P_0$$
$$\left|\frac{dP}{d\lambda}\right| = |P_1 - P_0|$$

因此：
$$\Delta s = \left|\frac{dP}{d\lambda}\right| \Delta\lambda = |P_1 - P_0| \cdot \lambda_{diff}$$

令 $\Delta s = dstep$，解得：
$$\lambda_{diff} = \frac{dstep}{|P_1 - P_0|}$$

代码中使用平方根形式与此等价：
$$\lambda_{diff} = \sqrt{\frac{dstep^2}{(x_{end}-x_{start})^2 + (y_{end}-y_{start})^2}} = \frac{dstep}{|P_1 - P_0|}$$

### 3.3 get_point — 位置计算

```cpp
void LinearBezier::get_point(float lambda, float &x, float &y) {
    x = params_.x_start*(1-lambda) + params_.x_end*lambda;
    y = params_.y_start*(1-lambda) + params_.y_end*lambda;
}
```

直接实现数学公式 $P(\lambda) = (1-\lambda)P_0 + \lambda P_1$。

### 3.4 lambda_velocity — 恒定速度控制

```cpp
float LinearBezier::lambda_velocity(float lambda, float velocity) {
    float lambda_vel;
    lambda_vel = std::sqrt(
        std::pow(velocity, 2) / 
        (std::pow(params_.x_end - params_.x_start, 2) + 
         std::pow(params_.y_end - params_.y_start, 2))
    );
    return lambda_vel;
}
```

**数学推导**：

对于线性贝塞尔：
$$\frac{dP}{d\lambda} = P_1 - P_0$$

令 $P_x = h(\lambda)$, $P_y = k(\lambda)$，则：
$$\frac{dh}{d\lambda} = x_{end} - x_{start}, \quad \frac{dk}{d\lambda} = y_{end} - y_{start}$$

根据 README 中的恒定速度公式：
$$\dot{\lambda} = \sqrt{\frac{V^2}{\left(\frac{dh}{d\lambda}\right)^2 + \left(\frac{dk}{d\lambda}\right)^2}}$$

代入得：
$$\dot{\lambda} = \sqrt{\frac{V^2}{(x_{end}-x_{start})^2 + (y_{end}-y_{start})^2}}$$

**注意**：线性贝塞尔的 $\dot{\lambda}$ 是**常数**（与 $\lambda$ 无关），因为 $\frac{dP}{d\lambda}$ 是常量。这意味着虚拟机器人在直线段上以恒定速度运动时，参数 $\lambda$ 线性增长。

### 3.5 get_velocity — 速度向量

```cpp
void LinearBezier::get_velocity(float lambda, float lambda_vel, float &vx, float &vy) {
    vx = (params_.x_end - params_.x_start) * lambda_vel;
    vy = (params_.y_end - params_.y_start) * lambda_vel;
}
```

链式法则：
$$\vec{v} = \frac{dP}{dt} = \frac{dP}{d\lambda} \cdot \dot{\lambda} = (P_1 - P_0) \cdot \dot{\lambda}$$

## 四、二次贝塞尔曲线（QuadraticBezier）

### 4.1 数学基础

$$P(\lambda) = (1-\lambda)^2 P_0 + 2(1-\lambda)\lambda P_1 + \lambda^2 P_2$$

### 4.2 构造函数与外延线段

```cpp
QuadraticBezier::QuadraticBezier(Params params):params_(params){
    float mag = 
        std::sqrt(std::pow(params_.x_start - params_.x_inter, 2) + std::pow(params_.y_start - params_.y_inter, 2)) +
        std::sqrt(std::pow(params_.x_inter - params_.x_end, 2) + std::pow(params_.y_inter - params_.y_end, 2));

    lambda_diff = params_.dstep / mag;

    // 创建外延线段
    LinearBezier::Params line_params;
    line_params.x_start = params_.x_start;
    line_params.y_start = params_.y_start;
    line_params.x_end   = params_.x_inter;
    line_params.y_end   = params_.y_inter;
    line_before = new LinearBezier(line_params);

    line_params.x_start = params_.x_inter;
    line_params.y_start = params_.y_inter;
    line_params.x_end   = params_.x_end;
    line_params.y_end   = params_.y_end;
    line_after = new LinearBezier(line_params);
}
```

**lambda_diff 的推导**：

二次贝塞尔曲线的控制多边形由两条线段组成：$P_0 \to P_1$ 和 $P_1 \to P_2$。代码用控制多边形的总长度近似曲线的几何长度：
$$mag = |P_0 - P_1| + |P_1 - P_2|$$
$$\lambda_{diff} = \frac{dstep}{mag}$$

这是一个**近似**，因为二次贝塞尔曲线的实际弧长通常小于控制多边形长度。但对于搜索步长而言，这种近似是合理的。

**外延线段（line_before / line_after）**：

这是一个关键设计。当 $\lambda < 0$ 或 $\lambda > 1$ 时，二次贝塞尔公式仍然可以计算，但物理意义是"曲线向外的延伸"。代码选择用**线性外延**替代：
- $\lambda < 0$：使用 $P_0 \to P_1$ 的线段向 $P_0$ 外侧延伸；
- $\lambda > 1$：使用 $P_1 \to P_2$ 的线段向 $P_2$ 外侧延伸。

这样做的好处是：在路径规划器的搜索过程中，虚拟机器人可以"超出"当前贝塞尔段的定义域，而不会遇到数值异常。

### 4.3 get_point — 位置计算

```cpp
void QuadraticBezier::get_point(float lambda, float &x, float &y){
    if (lambda < 0){
        line_before->get_point(lambda, x, y);
    }
    else if (lambda > 1){
        line_after->get_point(lambda, x, y);
    }
    else{
        x = std::pow(1-lambda, 2) * params_.x_start 
          + 2*lambda*(1-lambda) * params_.x_inter 
          + std::pow(lambda, 2) * params_.x_end;
        y = std::pow(1-lambda, 2) * params_.y_start 
          + 2*lambda*(1-lambda) * params_.y_inter 
          + std::pow(lambda, 2) * params_.y_end;
    }
}
```

### 4.4 lambda_velocity — 恒定速度控制

```cpp
float QuadraticBezier::lambda_velocity(float lambda, float velocity){
    if (lambda < 0){
        return line_before->lambda_velocity(lambda, velocity);
    }
    else if (lambda > 1){
        return line_after->lambda_velocity(lambda, velocity);
    }
    else{
        float lambda_vel;
        lambda_vel = std::sqrt(
            std::pow(velocity, 2) / 
            (std::pow(
                -2*(1-lambda)*params_.x_start + (2-4*lambda)*params_.x_inter + 2*lambda*params_.x_end, 
             2) + 
             std::pow(
                -2*(1-lambda)*params_.y_start + (2-4*lambda)*params_.y_inter + 2*lambda*params_.y_end, 
             2))
        );
        return lambda_vel;
    }
}
```

**数学推导**：

对二次贝塞尔求导：
$$\frac{dP}{d\lambda} = -2(1-\lambda)P_0 + (2-4\lambda)P_1 + 2\lambda P_2$$

验证：
- 当 $\lambda = 0$：$\frac{dP}{d\lambda} = -2P_0 + 2P_1 = 2(P_1 - P_0)$（方向沿 $P_0 \to P_1$）
- 当 $\lambda = 1$：$\frac{dP}{d\lambda} = -2P_1 + 2P_2 = 2(P_2 - P_1)$（方向沿 $P_1 \to P_2$）

代入恒定速度公式：
$$\dot{\lambda} = \sqrt{\frac{V^2}{\left(\frac{dP_x}{d\lambda}\right)^2 + \left(\frac{dP_y}{d\lambda}\right)^2}}$$

**注意**：二次贝塞尔的 $\dot{\lambda}$ **不是常数**，而是 $\lambda$ 的函数。这意味着虚拟机器人在曲线段上运动时，参数 $\lambda$ 的增长速度会随位置变化。

### 4.5 get_velocity — 速度向量

```cpp
void QuadraticBezier::get_velocity(float lambda, float lambda_vel, float &vx, float &vy){
    if (lambda < 0){
        line_before->get_velocity(lambda, lambda_vel, vx, vy);
    }
    else if (lambda > 1){
        line_after->get_velocity(lambda, lambda_vel, vx, vy);
    }
    else{
        vx = (-2*(1-lambda)*params_.x_start + (2-4*lambda)*params_.x_inter + 2*lambda*params_.x_end) * lambda_vel;
        vy = (-2*(1-lambda)*params_.y_start + (2-4*lambda)*params_.y_inter + 2*lambda*params_.y_end) * lambda_vel;
    }
}
```

## 五、三次贝塞尔曲线（CubicBezier）

### 5.1 数学基础

$$P(\lambda) = (1-\lambda)^3 P_0 + 3(1-\lambda)^2\lambda P_1 + 3(1-\lambda)\lambda^2 P_2 + \lambda^3 P_3$$

### 5.2 构造函数与外延线段

```cpp
CubicBezier::CubicBezier(Params params):params_(params){
    float mag = 
        std::sqrt(std::pow(params_.x_start - params_.x_inter1, 2) + std::pow(params_.y_start - params_.y_inter1, 2)) +
        std::sqrt(std::pow(params_.x_inter1 - params_.x_inter2, 2) + std::pow(params_.y_inter1 - params_.y_inter2, 2)) + 
        std::sqrt(std::pow(params_.x_inter2 - params_.x_end, 2) + std::pow(params_.y_inter2 - params_.y_end, 2));

    lambda_diff = params_.dstep / mag;

    // 外延线段：P0->P1 和 P2->P3
    LinearBezier::Params line_params;
    line_params.x_start = params_.x_start;
    line_params.y_start = params_.y_start;
    line_params.x_end   = params_.x_inter1;
    line_params.y_end   = params_.y_inter1;
    line_before = new LinearBezier(line_params);

    line_params.x_start = params_.x_inter2;
    line_params.y_start = params_.y_inter2;
    line_params.x_end   = params_.x_end;
    line_params.y_end   = params_.y_end;
    line_after = new LinearBezier(line_params);
}
```

**lambda_diff 的推导**：

三次贝塞尔的控制多边形由三条线段组成：$P_0 \to P_1 \to P_2 \to P_3$。
$$mag = |P_0 - P_1| + |P_1 - P_2| + |P_2 - P_3|$$
$$\lambda_{diff} = \frac{dstep}{mag}$$

### 5.3 get_point — 位置计算

```cpp
void CubicBezier::get_point(float lambda, float &x, float &y){
    if (lambda < 0){
        line_before->get_point(lambda, x, y);
    }
    else if (lambda > 1){
        line_after->get_point(lambda, x, y);
    }
    else{
        x = std::pow(1-lambda, 3) * params_.x_start 
          + 3*std::pow(1-lambda, 2)*lambda * params_.x_inter1 
          + 3*(1-lambda)*std::pow(lambda, 2) * params_.x_inter2 
          + std::pow(lambda, 3) * params_.x_end;
        y = std::pow(1-lambda, 3) * params_.y_start 
          + 3*std::pow(1-lambda, 2)*lambda * params_.y_inter1 
          + 3*(1-lambda)*std::pow(lambda, 2) * params_.y_inter2 
          + std::pow(lambda, 3) * params_.y_end;
    }
}
```

### 5.4 lambda_velocity — 恒定速度控制

```cpp
float CubicBezier::lambda_velocity(float lambda, float velocity){
    if (lambda < 0){
        return line_before->lambda_velocity(lambda, velocity);
    }
    else if (lambda > 1){
        return line_after->lambda_velocity(lambda, velocity);
    }
    else{
        float lambda_vel;
        lambda_vel = std::sqrt(
            std::pow(velocity, 2) / 
            (std::pow(
                -3*std::pow(1-lambda, 2)*params_.x_start 
                + (-6*(1-lambda)*lambda + 3*std::pow(1-lambda, 2))*params_.x_inter1 
                + (-3*std::pow(lambda, 2) + 6*(1-lambda)*lambda)*params_.x_inter2 
                + 3*std::pow(lambda, 2)*params_.x_end, 
             2) + 
             std::pow(
                -3*std::pow(1-lambda, 2)*params_.y_start 
                + (-6*(1-lambda)*lambda + 3*std::pow(1-lambda, 2))*params_.y_inter1 
                + (-3*std::pow(lambda, 2) + 6*(1-lambda)*lambda)*params_.y_inter2 
                + 3*std::pow(lambda, 2)*params_.y_end, 
             2))
        );
        return lambda_vel;
    }
}
```

**数学推导**：

对三次贝塞尔求导：
$$\frac{dP}{d\lambda} = -3(1-\lambda)^2 P_0 + [3(1-\lambda)^2 - 6(1-\lambda)\lambda] P_1 + [6(1-\lambda)\lambda - 3\lambda^2] P_2 + 3\lambda^2 P_3$$

代码中的导数表达式与上式完全对应：
- $P_0$ 系数：$-3(1-\lambda)^2$
- $P_1$ 系数：$-6(1-\lambda)\lambda + 3(1-\lambda)^2$
- $P_2$ 系数：$-3\lambda^2 + 6(1-\lambda)\lambda$
- $P_3$ 系数：$3\lambda^2$

### 5.5 get_velocity — 速度向量

```cpp
void CubicBezier::get_velocity(float lambda, float lambda_vel, float &vx, float &vy){

        vy = (-3*std::pow(1-lambda, 2)*params_.y_start 
            + (-6*(1-lambda)*lambda + 3*std::pow(1-lambda, 2))*params_.y_inter1 
            + (-3*std::pow(lambda, 2) + 6*(1-lambda)*lambda)*params_.y_inter2 
            + 3*std::pow(lambda, 2)*params_.y_end) * lambda_vel;
    }
}
```

## 六、恒定速度控制的统一数学框架

三种贝塞尔曲线的恒定速度控制遵循统一模式：

### 6.1 通用公式

给定参数曲线 $P(\lambda) = [h(\lambda), k(\lambda)]^T$，要求 $|\frac{dP}{dt}| = V$：

$$\frac{dP}{dt} = \frac{dP}{d\lambda} \cdot \frac{d\lambda}{dt} = \left[\frac{dh}{d\lambda}, \frac{dk}{d\lambda}\right]^T \cdot \dot{\lambda}$$

$$V^2 = \left(\frac{dh}{d\lambda}\right)^2 \dot{\lambda}^2 + \left(\frac{dk}{d\lambda}\right)^2 \dot{\lambda}^2 = \left[\left(\frac{dh}{d\lambda}\right)^2 + \left(\frac{dk}{d\lambda}\right)^2\right] \dot{\lambda}^2$$

解得：
$$\dot{\lambda} = \sqrt{\frac{V^2}{\left(\frac{dh}{d\lambda}\right)^2 + \left(\frac{dk}{d\lambda}\right)^2}}$$

### 6.2 不同阶次的特性对比

| 特性 | 线性 | 二次 | 三次 |
|---|---|---|---|
| $\frac{dP}{d\lambda}$ | 常数 | $\lambda$ 的线性函数 | $\lambda$ 的二次函数 |
| $\dot{\lambda}$ | **常数** | 随 $\lambda$ 变化 | 随 $\lambda$ 变化 |
| 速度方向 | 恒定 | 连续变化 | 连续变化 |
| 曲率 | 0 | 连续变化 | 连续变化 |

**关键洞察**：只有线性贝塞尔的 $\dot{\lambda}$ 是常数。对于二次和三次贝塞尔，$\dot{\lambda}$ 必须在每个时间步重新计算，因为切向量的模长随位置变化。

### 6.3 代码中的实现模式

所有三种贝塞尔曲线的 `lambda_velocity` 函数遵循相同模式：

```cpp
float lambda_velocity(float lambda, float velocity) {
    // 1. 计算 dP/dlambda 的 x 分量
    float dpx = dh/dlambda 的表达式;
    // 2. 计算 dP/dlambda 的 y 分量  
    float dpy = dk/dlambda 的表达式;
    // 3. 代入恒定速度公式
    return sqrt(velocity^2 / (dpx^2 + dpy^2));
}
```

## 七、Map 类 — 分段贝塞尔路径的组合器

### 7.1 设计动机

实际路径通常由多段贝塞尔曲线拼接而成。`Map` 类提供一个**全局参数空间**，使得路径规划器可以用单一的 $\lambda$ 值访问整个路径，而无需关心当前位于哪一段。

### 7.2 全局参数映射机制

```cpp
void Map::get_point(float lambda, float &x, float &y) {
    int index = std::floor(lambda);           // 提取整数部分 = 段索引
    index = std::min(std::max(index, 0), num_curves - 1);  // 钳制到有效范围
    lambda -= index;                          // 提取小数部分 = 段内参数

    curves_[index]->get_point(lambda, x, y);  // 委托给具体曲线段
}
```

**映射规则**：
- 第 0 段贝塞尔曲线对应 $\lambda \in [0, 1)$
- 第 1 段贝塞尔曲线对应 $\lambda \in [1, 2)$
- 第 $n$ 段贝塞尔曲线对应 $\lambda \in [n, n+1)$

**示例**：
- `lambda = 0.5` → 第 0 段，`local_lambda = 0.5`
- `lambda = 1.3` → 第 1 段，`local_lambda = 0.3`
- `lambda = 2.8` → 第 2 段，`local_lambda = 0.8`

### 7.3 分段连接处的连续性

代码本身**不保证**相邻贝塞尔段在连接处的切向连续性（$C^1$ 连续）。这意味着：
- 如果两段贝塞尔曲线的控制点未精心设计，虚拟机器人在段边界处可能经历速度方向的突变；
- 这种突变会被模块一的代价函数中的 `smooth_cost` 项惩罚，但不会被主动消除。

**实践中**：演示中的 stair-like 路径由三段线性贝塞尔组成，在连接处是 $C^0$ 连续但非 $C^1$ 连续。由于线性贝塞尔本身代表直线段，机器人在转角处需要转弯，这恰好与任务场景一致。

### 7.4 get_lambda_diff — 为搜索提供步长

```cpp
float Map::get_lambda_diff(float lambda){
    int index = std::floor(lambda);
    index = std::min(std::max(index, 0), num_curves - 1);
    return curves_[index]->lambda_diff;
}
```

模块三（`tracking()`）使用此函数获取当前段对应的搜索步长。由于不同段的弧长不同，每段的 `lambda_diff` 也不同，确保搜索步长在几何空间中大致均匀。

## 八、与 README 数学公式的精确对应

| README 公式 | 代码实现 | 位置 |
|---|---|---|
| $P = (1-\lambda)P_0 + \lambda P_1$ | `x = params_.x_start*(1-lambda) + params_.x_end*lambda` | `LinearBezier::get_point` |
| $P = (1-\lambda)^2 P_0 + 2(1-\lambda)\lambda P_1 + \lambda^2 P_2$ | `std::pow(1-lambda,2)*params_.x_start + 2*lambda*(1-lambda)*params_.x_inter + std::pow(lambda,2)*params_.x_end` | `QuadraticBezier::get_point` |
| $P = (1-\lambda)^3 P_0 + 3(1-\lambda)^2\lambda P_1 + 3(1-\lambda)\lambda^2 P_2 + \lambda^3 P_3$ | 对应展开式 | `CubicBezier::get_point` |
| $\dot{P_x} = \frac{dh}{d\lambda} \dot{\lambda}$ | `vx = (dh/dlambda) * lambda_vel` | 所有 `get_velocity` |
| $\dot{\lambda} = \sqrt{\frac{V^2}{(dh/d\lambda)^2 + (dk/d\lambda)^2}}$ | `sqrt(pow(velocity,2) / (pow(dpx,2) + pow(dpy,2)))` | 所有 `lambda_velocity` |

## 九、关键设计决策与潜在问题

### 9.1 设计决策分析

**决策 1：用控制多边形长度近似弧长计算 lambda_diff**

二次和三次贝塞尔曲线的 `lambda_diff` 使用控制多边形的折线长度而非真实弧长。这是一种计算高效的近似，但会导致：
- 搜索步长在曲线段的几何空间中不完全均匀；
- 对于高曲率段（控制多边形与曲线偏差大），近似误差更大。

**决策 2：线性外延处理 $\lambda \notin [0, 1]$**

当搜索或仿真使虚拟机器人"超出"当前贝塞尔段的定义域时，代码使用线性线段外延。这比直接套用高阶贝塞尔公式更稳定，因为：
- 高阶贝塞尔在 $\lambda < 0$ 或 $\lambda > 1$ 时可能产生不合理的回环或剧烈弯曲；
- 线性外延提供了自然的"路径延续"行为。

但缺点是：在段边界处，从贝塞尔曲线切换到线性外延会导致曲率突变。

**决策 3：使用 `float` 而非 `double`**

所有计算使用单精度浮点数。对于本项目中的场景规模和精度要求，`float` 通常足够，但在以下情况可能产生问题：
- 极长路径（$\lambda$ 值很大时，`float` 的精度损失）；
- 极高曲率（导数计算中的抵消误差）。

### 9.2 潜在问题

| 问题 | 场景 | 影响 |
|---|---|---|
| 切向量为零 | 控制点共线或重合导致 $\frac{dP}{d\lambda} = 0$ | `lambda_velocity` 中除以零，产生 `inf` 或运行时异常 |
| $C^0$ 但非 $C^1$ 连接 | 相邻段控制点未对齐 | 虚拟机器人在段边界处速度方向突变，影响跟踪平滑性 |
| 参数空间到几何空间的非线性映射 | 高曲率三次贝塞尔段 | 固定的 $\lambda$ 步长对应不同的几何步长，搜索效率不均 |
| `dstep` 参数敏感 | 不同路径段长度差异大 | 统一的 `dstep` 可能导致某些段的 `lambda_diff` 过大或过小 |

### 9.3 与模块一的交互要点

模块一（`pursuitcurve_sim`）中调用模块二的关键代码段：

```cpp
// 获取理想机器人位置
params_.map->get_point(lambda, x_lead, y_lead);

// 计算恒定速度参数变化率
lambda_vel = params_.map->lambda_velocity(lambda, params_.vel);

// 获取理想机器人速度向量
params_.map->get_velocity(lambda, lambda_vel, vx_lead, vy_lead);
```

这三行代码是模块一和模块二之间的**唯一接口**。`Map` 类的多态封装使得模块一完全不需要关心底层是哪种贝塞尔曲线——它只需要一个全局参数 $\lambda$，就能得到位置和速度。

## 十、小结

模块二的实现展现了**经典参数曲线理论**与**工程实践**的紧密配合：

1. **贝塞尔曲线的阶次选择**：线性用于直线路径，二次/三次用于平滑曲线路径。代码通过继承体系提供了统一的接口；
2. **恒定速度控制**是模块二最核心的数学贡献——通过链式法则将物理速度约束转化为参数变化率 $\dot{\lambda}$，使得虚拟机器人的运动学完全确定；
3. **分段组合与全局参数映射**（`Map` 类）将多段路径封装为单一参数空间，大大简化了模块一的接口设计；
4. **外延线段**的设计是一个务实的工程选择，确保了搜索和仿真在段边界处的数值稳定性。

**最值得关注的技术细节**：
- 三次贝塞尔 `lambda_velocity` 中的导数表达式是手工展开的多项式，虽然正确但冗长，容易因代码错误引入 bug；
- `lambda_diff` 使用控制多边形长度近似弧长，是一种计算高效的合理近似，但在高曲率段存在系统误差；
- 项目未提供段间切向连续性（$C^1$）的自动检查或强制机制，需要用户在定义控制点时自行保证。
